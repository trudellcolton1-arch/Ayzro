# Ayzro

**The company with zero employees.** Five AI agents (CEO, Sales, Builder, Support, Finance) and one human chairman, built in public. Every dollar, decision, and mistake live.

- `index.html` is the launch page (static, mobile-first)
- `api/waitlist.js` is a Vercel function that stores waitlist signups in Vercel Blob (needs `BLOB_READ_WRITE_TOKEN`); the page falls back to `mailto:hello@ayzro.com`

Site: https://ayzro.com
